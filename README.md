# TFM-GENES

Bioinformatics pipeline for the analysis of genes associated with **ADHD** (Attention Deficit Hyperactivity Disorder) and **HCI** (High Cognitive Intelligence / Cognitive Performance).

The project integrates data from multiple public access sources (MyGene.info, Reactome, GWAS Catalog) into a MySQL relational database, enabling the automated analysis of shared molecular pathways between both phenotypes.

## Execution Pipeline

```
genes.xlsx  (data/input/)
    │
    ▼
[STEP 1] Gene Mapping          → resultados_1.xlsx     (MyGene.info + Reactome)
    │
    ▼
[STEP 2] GWAS Query            → resultados_gwas.xlsx  (GWAS Catalog / EBI)
    │
    ▼
[STEP 3] Intermediate Builder  → intermedio_bd.xlsx    (normalized tables)
    │
    ▼
[STEP 4] Create Database       → genes_2e (MySQL schema)
    │
    ▼
[STEP 5] Load Data             → Transactional INSERT / UPSERT in MySQL
    │
    ▼
[STEP 6] Queries               → ADHD ↔ HCI shared pathways analysis
```

## Prerequisites & Installation

### 1. System Requirements

- Python **3.9** or higher
- MySQL Server **8.0** or higher running on the default port (`3306`)

### 2. Clone & Install Dependencies

```bash
# Clone the repository
git clone [https://github.com/your-username/TFM-GENES.git](https://github.com/your-username/TFM-GENES.git)
cd TFM-GENES

# Create a virtual environment (recommended)
python -m venv venv
source venv/bin/activate       # Linux / macOS
venv\Scripts\activate          # Windows

# Install dependencies
pip install -r requirements.txt
```

### 3. Credentials Configuration
Database credentials **are not hardcoded** into the source code; they are loaded from a local `.env` file:

```bash
cp .env.example .env
```

Edit `.env` with your MySQL server details:

```ini,TOML
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password_here
DB_NAME=genes_2e
```

### 4. Input File
Place the `genes.xlsx` file inside `data/input/`. It must contain two sheets:

| Sheet | Required Column |
|------|---------------------|
| `TDAH` | `gen` (Gene Symbol) |
| `ACI` | `gen` (Gene Symbol) |

## Usage

### Full Execution (End-to-End)

```bash
python main.py
```

### Executing Individual Steps

```bash
python main.py --step 1   # ID mapping + Reactome extraction
python main.py --step 2   # GWAS variant extraction
python main.py --step 3   # Intermediate file construction
python main.py --step 4   # MySQL schema initialization
python main.py --step 5   # Relational insertion with duplicate handling
```

### Resuming from a Specific Step

```bash
python main.py --from 3   # Ejecuta desde el paso 3 hasta el final
```
> **API Caching**: Steps 1 and 2 automatically cache server responses into `data/cache/`.
>If the process is interrupted, restarting it will fetch previously queried genes from the cache without making new API requests<>

## Database Schema: `genes_2e`

```
genes ──────┐
            │
fenotipos ──┼──► asociaciones ◄──── variantes
            │
vias ───────┘        │
                     └──► articulos
```

| Table | Description |
|-------|-------------|
| `genes` | Evaluated genes mapped with molecular identifiers (Entrez, Ensembl, UniProt) |
| `fenotipos` | Traits under study (ADHD / HCI) with EFO identifiers |
| `vias` | Curated biological pathways extracted from Reactome |
| `articulos` | Indexed GWAS publications (Primary Key: PMID) |
| `variantes` | Genetic variants (rsID) with associated p-values |
| `asociaciones` | Bridge table: Gene ↔ Phenotype ↔ Pathway ↔ Variant ↔ Article |
